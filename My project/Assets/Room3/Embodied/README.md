# ROOM3：原有档案路线与具身交互的结合

本轮在原 ROOM3 上增补，没有重建场景或替换原有回环系统。

## 路线与操作

1. ROOM2 捕获三份残影、开启原出口后，仍通过既有传送器进入 ROOM3。新气动门放在 ROOM3 入场侧，避免在 ROOM2 的捕获门再叠一道相同门锁。入场点稍向后移，能看到阀门及门面。
2. 对准红色阀门按 E 握住，快速敲空格或点击鼠标左键积累气压。约 12—15 次有效敲击即可完成。停手超过 0.35 秒后气压与门板回落；E / ESC 放手。完成后门永久锁定在抬起位置，恢复玩家输入并移除门槛碰撞。
3. 原观察玻璃、侧向缺口、医疗档案、两次回环、劳工对照档案保留。新声呐不代替这些叙事节点。
4. 按住 RMB 每 3.1 秒发出一次同位素脉冲，以 23 米/秒传播。地面圆环扩散；悬垂的提取线、束缚环与抽象女工残影按其与发射点的距离依次显影，随后衰退。不是通过一个巨大点光源同时照亮全部对象。原通路及防跌落保持可辨认。
5. 桥仍要求医疗记录与劳工档案保留。站在原地标附近，准星稳定对齐目标约 1.15 秒；现在不需同时按 RMB。三块混凝土依次快速砸合，声音、有限震屏与尘埃在落稳点触发。全部到位后才开放连续碰撞。
6. 桥边有一枚手工制作的夜光表盘和一件抽象计算卡。对准时轻微拉近视野，按住 E 约 1.5 秒保留片段，产生少量绿色抖动与跨时代混音。两件物品是可选补充，不增加强制门锁。离开、阅读、暂停、结局及切场恢复 FOV；兼容工程现有 CinemachineVirtualCamera。
7. 原法庭档案、五名女性的象征性剪影和宣誓保留。普通操作仍为 LMB + 鼠标上推，另保留按住 E 的替代操作及 M 减少动态。完成时出现胸口绿光、粒子和最后一段通路，原有门碰撞与检查点继续控制通行。
8. 终局改为大字 FORMATTA / CUSTODISCI。悬停格式化会压低绿光并使环境去色，配合电流音；悬停保留会出现柔和绿色光幕与合成管风琴和声。离开按钮恢复光照、材质覆盖与声音，ESC 可返回探索。
9. 两个结局后果保留：格式化实际返回 ROOM1，并关闭本轮的 ROOM2 入口；保留则停止悬浮建筑和核心运动，显示历史姓名与论文原照片，姓名在裁切窗口中缓缓上移。重开恢复当前小镇的广告揭露流程，入口仍需按原流程解锁。

## 表达边界

- 未把“1927 年五人都因骨碎无法抬手”加入史实说明；宣誓仍标为象征性重构，沿用原法庭时间线和出处。
- 表盘、计算卡、绿线、光幕、声音均为本原型的艺术表现。新增七段声音由脚本合成，不冒充历史工人录音，也没有合成假证词。
- 原劳工档案仍明确两类工作的差异，保留数据标注、检查、过滤等劳动说明。
- 保留原有字体和 uGUI。新增简洁大字界面在打开时重新适配字体设置，背景的场景标签暂时隐藏以避免穿过正文。
