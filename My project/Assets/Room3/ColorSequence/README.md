## 美术与论文判断

采用用户提出的绿→黑→冷白→骨白金，但把它落实为与空间、宣誓和决策关联的变化。参考图的价值是明暗层级、尺度与剪影构图，不能仅靠高强度灯光宣称达到《Control》或3A级质量。

- 绿：表现危险暴露和劳动身体承受的代价。颜色是叙事象征，不是历史环境或辐射的科学可视化。
- 黑：使失去的记录、不可见的劳动成为空间经验；仍保留极少的地面定位点，避免故事被迷路打断。
- 冷白：身体被审查、测量、归类的状态。人物是五个有差异的见证者，避免重新简化成骷髅或恐怖玩偶。
- 骨白金：宣誓后，玩家承担保存证据的责任。封存悬停保留暖色，格式化悬停撤去暖色并降饱和，避免对两个选择一律加上神圣滤镜。

论文可讨论“可见性如何被系统分配”“身体如何从审查对象转为见证主体”。历史镭女工与当代数字劳动之间是作品提出的结构类比，需要文献论证，不能仅凭绿色视觉建立事实等同。以上为创作解释，尚不是经过参与者研究证实的叙事效果，也没有直接改写论文。

## 实际实现

|阶段|实现与位置|节奏|
|---|---|---|
|入口毒绿|防爆门外约10m，原生粒子局部雾、已装URP体积雾、绿光及空间蒸汽声；精确色值39FF14|实际跨门后保持3秒，再1.3秒平滑退去；仅触发一次。减少动态时峰值52%，2.4秒淡出；阅读/暂停时计时停止|

|冷白|五位见证者上方(0,8.1,40.6)向下聚光，E0FFFF；已装体积散射配合柔化开放光锥、微尘|宣誓前保留身体的低照度细节，远景仍黑|
|骨白金|终端后方z122聚光、z119辅助光与z126柔和发光背景；主色F5F5DC，克制金色外缘|宣誓后2.1秒切换，冷白归零；减少动态3.5秒。决策悬停接入原Preview；正式结局后关闭|

保留现有宣誓点z38、终端z96与核心构筑物。五名女工位于终端前的宣誓区，剪影高潮发生在宣誓开门的视线中；玩家随后沿微弱暖色路标前往终端。这是依据现有叙事空间作的调整，没有强搬人物到终端前。

采用独立优先级80 Volume，运行时实例化profile，使用已有渲染器与体积雾包。HDR相机、后处理链、ACES与Bloom有界控制；没有用一个无限亮的Point Light代替完整画面。终端面板提高遮罩不透明度，临近终端收起常驻HUD，保留原两项决策和按钮行为。场景仍有抽象构筑物、现代服装与原型UI，不能当作历史服饰复原或最终商业级美术。
