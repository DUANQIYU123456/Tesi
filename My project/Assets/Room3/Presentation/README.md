# ROOM3 presentation refinement

Local scene assets for Luce Verde nelle Ossa, DUAN QIYU, 2026-11-18.

The fitted work garments and concealed lower-outfit meshes derive from the Microsoft Rocketbox models already included in the project. Original model attribution, revision and MIT license are preserved in `../Rocketbox/Models/SOURCES.json` and `../Rocketbox/Models/LICENSE.Microsoft.txt`. Source FBX models and original textures were not overwritten.

The garments are symbolic workwear, not a reconstruction of a particular period or a portrait of a historical worker. The rig uses skinning; it does not simulate cloth.

Witness radiance is a generated transparent radial texture using the standard URP Unlit shader. Its alpha is uncompressed. The black architectural gate frame remains real geometry. No new third-party package was installed for this pass.
