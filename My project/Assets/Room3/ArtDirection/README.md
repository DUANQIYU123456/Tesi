# ROOM3 艺术精修

这轮针对上一版的灰盒感、平均散布的碎块、图标式物件、均匀绿光和展示板式宣誓背景进行修改。原玻璃夹层、空间回环、劳工档案、拼桥、两条宣誓操作和双结局后果保留。

## 已完成

- 60 个漂浮混凝土碎块保留 18 个，改为不对称疏密组；部分重复楼板和楼梯收起，未拼桥块移出中央视线。原纸屑方片改为稀疏柔和尘点。
- 混凝土增加三轴投射法线、线性 ORM、微小梯度扰动及低频沉积变化。绿色电路减弱并打散，球面脉冲可沿混凝土表面扫过。
- 阀门改成圆管轮缘、圆形辐条、轮毂、螺纹与漆面缺损，并增加随气压转动的实体表针。抬门与回落改为带缓动的运动。
- 夜光表盘增加双层金属表圈、60 刻度、12 个手绘式数字、上弦结构、指针和细裂纹；显卡增加弯曲扇叶、机壳、散热片、板材、暗金接点及紧固件。
- 弯曲提取线替代直方条；女工残影以边缘显影为主；蒸汽与尘埃按粒子顶点透明度和寿命渐隐。
- 减轻泛光与灰雾，补充局部金属侧光和小型反射探针。五名宣誓者有不同的手臂与头部姿态；移除整块亮底板，改为后置、没有封口的柔和光雾，远端保留苍白轴线。
- 收起过大的世界空间物件标签，保留靠近时的 UI 提示，缩短已捕获提示文字。记忆物件在阅读、终局与暂停时停止摆动。

## 来源

实际接入的 GitHub 代码与只读候选严格分开，见 SOURCES.md。NoiseShader 为本轮实际使用的 MIT HLSL 代码，没有安装额外 UPM 包或替换渲染管线。

## 编辑与恢复

入口：Editor/Room3ArtPass.cs。Install 用于尚未安装精修层的场景，检测到已有根对象时会拒绝重复添加。RefineAirborneLayers / FinalizeWitnessLighting 用于局部调整。

根对象：`ROOM3 - Art direction refinement`。旧物件网格、直提取线、亮背景板等作为禁用备份保留，没有覆盖原网格资产。

原版备份：`Library/Room3ArtPassBackup/20261117_055101/`，保存完整 ROOM3、原相关脚本/着色器、Room3Atmosphere 以及 ROOM3 材质。

## 验证范围与局限

工作区 `outputs/Room3ArtPass/validation-route.json` 共 106 项功能检查通过，覆盖实际输入、控制器行走、回环、拼桥、两种宣誓路径、视野恢复、预览与两结局。部分准备采用定点放置与生产方法调用，不是陌生玩家验收。

106 项通过后，仅补调物件局部灯光、外壳色和宣誓光雾网格，并做了定点画面复核；没有再跑整条路线。最终画面见 10-compute-final.png / 11-testimony-final.png。早期 08/09 为复核中间状态，光雾穿过人物和封口圆盘已修正。

人物仍为抽象程序网格，手部、衣褶和动作表演需要后续专门制作。声音仍是上一轮的合成原型；本轮没有完成专业混音或硬件性能分析。完整后果与历史出处仍沿用原档案，不把象征性宣誓当成历史现场复原。
