## 发现的问题与处理

| 问题 | 对玩家的影响 | 修改 |
|---|---|---|
| 罗盘按最近距离选目标，没有充分考虑当前进度 | 可能把玩家引到尚未解锁的出口，或跳过眼前应完成的线索 | ROOM2 按瓶子 → 未解码声源 → 病历 → 出口推进；ROOM3 对应玻璃缺口、校准点、法庭档案、宣誓和核心控制台。 |
| 锁住的出口没有具体说明 | 容易被误认为传送门坏了 | 靠近并看向出口时显示缺少的 XII / III / VI，指针仍指向下一条可完成线索。 |
| 减少抖动未完整传递到监狱扫描 | 玩家在小镇选择的设置进入下一关后失效 | 刷新每个场景时应用设置，保留扫描的视觉信息并关闭其摄像机冲击。 |
| 缺少暂停和集中设置 | 阅读、演示中断、音量及鼠标速度调整不方便 | ESC 暂停 / 返回；加入主音量、观察灵敏度、减少抖动、大字号阅读与重新开始。 |
| 同一按键可能先关闭档案又触发另一层界面 | 关档案后可能意外打开暂停 | 明确输入顺序，检视界面优先消费 ESC。暂停期间也不推进 ROOM3 交互进度。 |
| 字体层级不足，较小的来源文字吃力 | 玩家要靠近屏幕才能读清 | 正文、标题、仪表分别分配字族成员；扩大档案版面与正文，增加约 15% 的大字号模式，关闭自动缩小。 |
| 已解码档案仍显示解码教程 | 玩家不清楚是否已完成 | 重开时使用“TRACE RETAINED”提示，已完成的涂层保持清除。 |
| 隐藏声波条仍每帧生成网格 | 浪费 UI 刷新 | 隐藏时停止重绘，可见时限制到约 30 Hz；表盘读数约 10 Hz 更新，身份装饰只在进度改变时更新。尚未做独立构建性能基准。 |
| 小镇灯光对象残留空脚本 | 反复出现告警，增加后续排错干扰 | 清理 19 个没有脚本引用、没有序列化配置的空组件。清理前后 20 盏灯的序列化参数逐一相等。 |

音量、灵敏度、阅读字号与减少抖动属于偏好设置。四枚刻度仍只记录当前运行，不是磁盘存档。

## 客观判断

当前已经有“寻找 → 解码 → 系统反馈 → 下一段路线 → 最终选择”的可玩闭环。本轮主要解决了这个闭环里容易被误认为故障或不知如何继续的环节。

仍不能仅凭自动测试确认的内容：

- **玩家是否理解历史联系。** 能收齐刻度，不等于理解了表盘劳动、当代屏幕劳动与权力遮蔽之间的比较。下一轮应找三名未看过论文的人独立试玩，结束后请他们用自己的话说出角色任务、一次发现及两种结局的区别。
- **视觉是否承载了叙事。** 《Control》的参考图不能替代本作自己的空间逻辑。ROOM3 需要继续围绕玻璃的两侧、被打断的通路和终局纪念空间组织注意力；增加粒子数量或更多强光不一定有效。
- **史料出处仍要整理到最终版本。** 论文提供的病变图片身份未确认，不能标作 Mollie；原始照片的馆藏、日期、图注仍需在最终作品与论文中对应核对。
- **原素材的一些碰撞与地形告警仍存在。** 本轮没有把尚未验证的告警直接当成游戏故障，也没有批量改动场景碰撞。需要围绕正常步行路线做进一步测试。

本轮自动测试覆盖输入、排版、跨场景状态与结局。它不等同于玩家对叙事、氛围或情感表达的评价。
