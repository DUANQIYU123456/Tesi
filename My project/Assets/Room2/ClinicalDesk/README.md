# ROOM2 烛光档案桌

2026-11-16，按小段本轮要求修改现有 ROOM2。未重建整个场景。

## 试玩

正常从 ROOM1 开始，进入监狱后穿过 `SM_Door_Prison` 第一道门。入口画廊压暗，桌上保留原来的书、两个骷髅、杯、碟和烛台，五个原有药瓶穿插摆放。中央是 1922 年医疗档案，右侧有木柄、铜箍、驼毛笔头及绿漆的毛笔模型。

靠近并看向纸面，按 E 打开现有 Bloodlines 检视框。五个药瓶这时才升起；按住左键在黑色区域拖动，黑墨逐渐擦开，细小墨尘散落，露出论文图 1.2 和用户指定的意大利语/中文绿字。刮除约一半后，其余涂层缓慢消散并保留记录。也支持长按 F 三秒的替代操作。

E、ESC 或 Close 关闭。未完成的记录再次打开时重新遮蔽；已保留记录可以重读。关闭后瓶子回落并恢复移动/视角。离开入口画廊后恢复原灯光。此记录独立于 ROOM1 已获得的 XII，不会因已有 XII 而自动提前显影。

## 实现范围

- `ClinicalDesk`：入口区域、照明过渡、五瓶落桌/浮起与本轮记录状态。
- `ClinicalDeskTarget`：中央病历的检视目标。
- `ClinicalDeskReader`：复用共享 UI 的锁定、关闭、暂停与字体基础，添加纸面、证据层、双语提示和画笔光标。
- `ClinicalCoating`：真实鼠标路径擦除、遮罩透明度与墨尘。
- `ClinicalDeskInstaller`：初次安装工具；已安装时不会覆盖当前摆放。完成后的手调位置保存在 ROOM2 场景。
- 旧药瓶的 `NarrativeInspectable`、`SurveyNode` 与接近发光脚本已禁用，模型和液体插件保留。
- 共享 `SurveyHUD` 与 `SurveyTypography` 仅接入新检视模式和对应任务/雷达优先级。

## 资源与真实性

临床图直接引用 `Assets/Room3/Story/Images/Clinical_Thesis_Fig1_2.png`。核对后它是一张病变临床照片，未生成新的 X 光片，也未声称图中患者就是 Mollie。图像没有被修改。

1922 年纸面为本项目排版重构，不能作为真实历史死亡证明引用。来源小字在检视面板中可见。手写绿字采用用户给定的艺术表达。

纸张摩擦、骨骼摩擦、盖革反馈为原创程序合成音效原型，不是历史录音或真实临床录音。双语提示与手写字使用栅格文字资源，避免现有拉丁字体缺少汉字。毛笔为本轮生成的原生 Mesh 和细笔毛线条。
