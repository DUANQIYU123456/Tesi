Used for short English milestone messages. The generated TMP asset contains a static 1024x1024 SDF16 atlas, sampling size 90 and padding 9. Long-form prose continues to use Inter. The opening title uses ManufacturingConsent supplied with Bloodlines UI, with its original license retained in that package.

Motion design references: https://github.com/mob-sakai/UIEffect (fade transitions) and https://github.com/Luca3317/TMPEffects (timed text visibility). These packages were studied, not installed or copied. SurveyMilestones implements a small local CanvasGroup/TMP presentation with reduced-motion support and existing chapter-state triggers.
