# ROOM3 人物、建筑与劳动场景完善 · 2026-11-18

已保存 Unity 主工程 `D:/NABA/Tesi/My project/Assets/Scenes/ROOM3.unity`。延续四段色彩与全英文界面，本轮主要改变人物衣服、肩臂动作和装饰建筑，并修复近景检查中发现的工作区灯光错位及终端可读性问题。

## 人物与服装

为五位宣誓者、三位玻璃后工作残影、六位高处记忆人物，共14人增加骨架蒙皮的长裙、围裙、肩带、腰带与部分口袋。裙摆使用连续外轮廓，配细小竖褶和实际几何折边；根据原模型包络做拟合，避免逐层复制原裙子造成横向硬棱。三种低饱和布色保留个体差异，未替换原面孔或人体骨架。

新增 ArchiveTextile.shader 表现低反光棉/毛料、细微织纹与使用色差，没有新增外部贴图或布料运行包。衣服由骨架蒙皮驱动，未加入实时布料物理。原上衣部分仍可见，这是一套象征性工作服轮廓，不能称为完成了1920年代历史服饰复原，也不是历史原告的真实肖像。

14件衣服合计31,592顶点，使用四个躯干骨骼与最多两骨权重；没有为衣服新增Collider。新增材质与绘制存在实际成本，本轮未进行目标硬件性能测评。

## 肩、肘、腕动作

重写 RocketboxWitness 的姿态部分，保留原故事流程与输入：

- 根据每副骨架的实际上臂/前臂长度解算肘、腕位置，限制目标在可达范围内，不通过拉伸骨头凑姿势。
- 抬手分为屈肘、向上伸展、转掌的连续过程；锁骨与肩部小幅参与，头颈随努力量轻微抬起。
- 五人有小幅进度错开、手掌高度与左右偏移，保留不同的休息手势；左手贴胸/搭手姿势限制额外腕部校正，减轻折腕感。
- 右手掌在最终宣誓时朝向玩家，手指保留微小屈曲，减少硬平板感。
- 人物使用自己的动作时钟；阅读、决策、暂停和结局时停止更新。减少动态关闭闲置起伏与微小摆动，宣誓动作仍响应原输入。

这些是程序化动作，未导入动作捕捉数据。

## 建筑与终端

222处无碰撞组件的装饰网格使用三种局部切角、不同断面的截面，覆盖脊椎主体/肋片、表盘标记、错层薄片、部分悬浮楼板与碎块。最终版本保留较大的平直面与窄倒角，撤掉第一版偏圆石的轮廓。它们仍是复用的三种变体，不能等同于222个独立手工模型。

表盘中心最终为y34，指针保持表盘局部原点；双螺旋根节点y10.5，中央石碑沿用上一轮y18.5。给抬起的手掌与上方构筑物留下间隔，保持五个人物的剪影可读。

三个既有档案终端增加凹入屏幕、窄金属边框、安静状态灯和通风口。屏幕直接显示英文 ARCHIVE / RETAINED TRACE 或 ARCHIVE / FINAL RECORD，并保留原[E]交互。新增 ArchiveConsoleSurface 只控制表面文字的显现：5m外淡出，靠近3.3m内完全可见；阅读、决策和结局时隐藏，避免在远景里成为悬空字。

## 检查中另外发现并修复的问题

1. 三盏旧工作灯还在x80，而目前工作人物和桌面位于x10。将其移回工作区附近，改成收束的局部聚光灯，照亮桌面、衣服和手部。三个灯的最终强度45、范围6m，次要灯的阴影固定为512，减少对主要光源阴影图集的占用；不改变全局黑色环境光。
2. 工作人物原来面向+Z，桌子在人物后方。校正为面向-Z，使手部回到桌面一侧，并保留小幅重复劳动动作。没有宣称做了精确手指接触或物理抓取。
3. 近距离宣誓提示仍写着 Prestare giuramento。已将运行时字幕改为 BEAR WITNESS / symbolic testimony。既有ERASE/PRESERVE、Inter字体与英文菜单继续保留。

## 与论文的关系及实际边界

服装与手势强化“劳动身体—审查对象—承担见证”的转换，玻璃后劳动不再因为旧灯位置错误而无法辨认。界面的 symbolic testimony 继续说明这是象征场景，避免把程序化宣誓当成历史庭审复演。

人物面部和部分原上衣仍有模型素材的时代痕迹；建筑仍有复用规律，动作仍是程序化。完成这一轮不代表用户已认可美术，也没有直接改写论文或证明观众会如何理解作品。
