更新：2026-11-12。

场景：`D:/NABA/Tesi/My project/Assets/Scenes/ROOM3.unity`。

- 单独预览：`Tools > Xiaoduan > ROOM3 > Preview ROOM3 on next Play`，然后点 Play。

- 停止 Play 后原有编辑器脚本会恢复从 ROOM1 开始；下次单独预览 ROOM3 时重新选择上述菜单。

## 四段路线与操作

### 1. 玻璃长廊 / 档案 VI

入口正前方有塌落结构。沿右侧绿色地面引导，穿过玻璃缺口进入夹层，看到隐藏的劳工剪影。到夹层尽头的档案台按 **E**。

- 按住 **F 或 Space** 约 1.3 秒显影另一层记录。
- **E / ESC / Close 按钮** 关闭。
- 解锁后再次阅读无需重新等待显影。
- 可自主显示临床参考图；默认显示论文中的 Mollie 肖像。
- 跟随出口横向绿色光带，提前左转回到中央走廊，绕开门框。

### 2. 视角校准断桥

站上桥头地面标记，按住 **鼠标右键**，让屏幕中央十字与空中绿色校准框重合。保持约 1.15 秒后桥梁开始归位。

三块模块约 2.5 秒完成锁定，随后开放碰撞与通行。桥面连续，不要求跳跃。未读档案不能提前解锁；朝错方向不会增加进度。

### 3. 法庭档案 IX / 宣誓门

过桥后左侧档案台为第二份记录，按 **E** 打开，按住 **F / Space** 显影。

读完后走近五个剪影下方的门：

- 普通方式：**按住左键并持续向上推鼠标**，累积约四秒有效输入。
- 替代方式：**长按 E** 约四秒。
- **M** 可随时切换减弱镜头干扰。

普通模式在此段临时收紧向上的视角范围，避免一直上推后只看见头顶；完成或退出交互后恢复原范围。没有真实降低游戏帧率。

门打开后五个剪影的象征性绿光亮起，可以进入下一段。

### 4. 硅骨深渊 / 核心抉择

沿较窄的金属梁走向双螺旋巨构和微芯片核心，在控制台按 **E**。可以用 ESC 关闭选择界面。

- **RESTORE ORDER / RIPRISTINA L'ORDINE**：返回小镇，关闭这一轮中的监狱入口，显示系统结语。
- **GUARD THE RUINS / CUSTODISCI LE ROVINE**：建筑、指针与齿轮停止漂移，开启纪念粒子，显示五位原告的姓名、Mollie 的纪念文字，以及论文中的两张人物照片。
- **R / Restart the survey 按钮** 重新开始，恢复小镇和传送门。

入口返回门在这版剧情里隐藏，符合进入后继续深入的结构。结局只影响当次运行，不修改源场景。

## 当前进度与材料

本场景记录的两份档案对应 VI 和 IX。ROOM1 / ROOM2 的全局四碎片库存尚未接入，界面没有把未实现的收集行为计为完成。

两个档案界面区分虚构公司界面、历史摘要、原报纸剪报与象征性重构。五个剪影为抽象的程序网格人物，没有假装成扫描得到的真人模型。

绿色骨骼与建筑是艺术表达，不是辐射在人体中发光的科学模拟。具体史料、时间线校正与肖像来源限制见 `STORY_SOURCES.md`。
