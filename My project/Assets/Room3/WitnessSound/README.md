# ROOM3 人物、材质与分段声音

本轮按用户要求改进最明显的假人感与拼装感，保留已完成的观察玻璃、回环、医疗/劳工/法庭档案、合桥、两种宣誓输入和双结局。

## 人物与场景

- 五名宣誓者、玻璃后的三名工作残影均替换为有实际人体拓扑和 53 骨架的模型。短发有三种，身高、头部、站位和手臂姿态区分；加入轻微呼吸与随宣誓进度抬手。编辑器里也保存自然姿态。
- 人物仍作为象征性的黑色女工剪影。模型并非历史人物肖像，也不是现场复原或真人扫描。
- 宣誓者移到平台，修正脚底接触、肩部连贯性与手掌朝向；胸口改为贴合衣服的细小绿光纹理与五处独立局部粒子，去掉原高空发射位置。
- 短袖长裙、鞋与部分工作围裙组成时代感衣着。围裙采用平滑边缘遮罩，避免用低密度三角面的边界做裁切；新网格资源避免旧 GPU 蒙皮缓存格式冲突。
- 门加金属板盒、接缝、框架与紧固件；平台改为粗糙混凝土，加入收敛的地面接缝和侧边排水细节。补柔和侧光，避免整张脸被胸口绿灯从下方照亮。

## 声音

新增 21 个片段、22 个原生 AudioSource，由场景内 Room3Soundscape 跟随原有剧情触发，未另建全局 Audio Manager。

1. 红阀门：低通工业警报；每次敲击有齿轮摩擦；停手有泄压/回落；锁死时重击、警报骤停、转入冷风。
2. 深渊：非旋律风声与低频底噪；右键发出低沉声呐并带延迟辐射细响。循环播放状态有持续维护。
3. 合桥：对齐最后约半秒切风声/底噪；桥初始低频撞击与三个模块的独立石块落稳声，含 4 秒以上尾音。
4. 记忆/宣誓：看怀表交叉淡入滴答与女性咳嗽，看计算卡切风扇/不规则点击；用力时张力音和心跳随进度变调；成功后进入管风琴与合唱。
5. 终端：抵达时切断风琴/合唱；格式化悬停为冷数字擦除，封存为木槌与温暖大调和弦；黑色姓名/肖像落幕只保留机械滴答，约 38 秒淡尽。

原生 AudioReverbZone 使用 Cave 基础参数并保存为 User，衰减 4.2 秒。二维音乐使用剪辑内空间尾音；空间声源使用混响区。并非所有声音都会自动具有三维定位。

## 验证范围

Final/validation-route.json：128 项编辑器流程检查通过，覆盖实际按键/鼠标、正常行走、回环、合桥、记忆、两种宣誓、悬停和双结局/重开，也检查环境循环与记忆声音确实在播放。部分准备和第二结局使用定点与生产方法，不是陌生玩家验收。

Final/audio-phase-samples.json 记录真实 AudioListener 输出；开场、深渊、朝圣、宣誓阶段均有实际混音信号。它是分阶段短时采样，不是整段录音、专业听评或完整响度/峰值分析；钟表的间歇滴答可在采样时刻处于安静间隔。

128 项之后只细化围裙边缘、胸口粒子锚点/纹理与成功配乐音量，另做定点显示、发射数量和 Console 检查。最终画面通过游戏自己的 ScreenCapture 保存，没有用后期提亮来代替工程照明。
